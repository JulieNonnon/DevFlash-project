# Personas

4 personas ont été déterminés avec une classification comme ci-dessous :
- Cible réelle directe
- Cible réelle indirecte
- Cible fictive directe
- Cible fictive indirecte

---

## 1. Cible réelle directe — Vincent

> Utilisateur directement concerné par le problème et cible prioritaire de DevFlash.

👤 Vincent Vigneron
| Élément          | Profil                                              |
|------------------|-----------------------------------------------------|
| Âge              | 20 ans                                              |
| Lieu             | Cergy-Pontoise, France                              |
| Activité         | Etudiant en première année de Licence Informatique  |
| Niveau technique | Débutant / Néophyte                                 |
| Langages         | JavaScript principalement, quelques bases de Python |

### 🌐 Comportement en ligne

Vincent utilise quotidiennement :

- Google pour rechercher des réponses à des problèmes techniques ;
- MDN et Stack Overflow ;
- YouTube pour suivre des tutoriels ;
- GitHub pour consulter des projets ;
- Des documentations officielles lorsqu'il veut approfondir une notion.

Il consulte énormément de ressources mais les utilise principalement au moment où il rencontre un problème.

Il lui arrive de sauvegarder des articles ou des vidéos avec l'intention de les consulter plus tard, sans forcément le faire.

### 🎯 Motivation et objectifs

Vincent souhaite :

- Consolider ses connaissances fondamentales ;
- Etre plus autonome dans son travail ;
- Mémoriser les méthodes et concepts qu'il utilise régulièrement ;
- Réviser ponctuellement sur le retour ;
- Avoir davantage confiance lorsqu'il code.

Son objectif est d'assimiler rapidement des notions et de transformer des connaissances ponctuelles en connaissances réellement mémorisées.

### ❤️ Intérêts et préférences

Il apprécie :

- Les formats courts ;
- Les exemples concrets ;
- Les interfaces simples ;
- Les explications directement applicables ;
- Les outils accessibles depuis son navigateur.

Il préfère une session rapide de 5 à 10 minutes plutôt qu'un cours de 45 minutes.

### 🚧 Défis et freins

- Son principal problème est la surcharge d'informations.
- Il connaît souvent une méthode lorsqu'il vient de la consulter, mais quelques jours plus tard il doit rechercher à nouveau sa syntaxe ou son fonctionnement.

Ses principaux freins :

- Manque de temps ;
- Difficulté à organiser ses révisions ;
- Accumulation de ressources ;
- Manque de régularité ;
- Impression de "perdre du temps" lorsqu'il révise plutôt que de coder.

### 💡 Ce que DevFlash lui apporte

- **Une manière rapide et structurée de transformer les notions qu'il consulte ponctuellement en connaissances mémorisées.**

Priorité : ⭐⭐⭐⭐⭐

## 2. Cible réelle indirecte — Manon

> Personne réellement concernée par le problème, mais qui n'est pas nécessairement l'utilisateur final prioritaire.

### 👤 Manon Kuor
| Élément    | Profil                                                    |
|------------|-----------------------------------------------------------|
| Âge        | 33 ans                                                    |
| Lieu       | Lyon, France                                              |
| Activité   | Formatrice / développeuse dans une école de programmation |
| Expérience | 6 ans dans le développement                               |
| Langages   | JavaScript, TypeScript, Python                            |

### 🌐 Comportement en ligne

Manon utilise :

- MDN ;
- GitHub ;
- Stack Overflow ;
- Des plateformes de formation ;
- Des ressources pédagogiques ;
- YouTube et des newsletters techniques.

Elle recherche régulièrement de nouvelles ressources à proposer à ses apprenants.

### 🎯 Motivation et objectifs

Manon souhaite :

- Mettre à disposition un outil d'entrainement simple, accessible et écologique pour ses apprenants;
- Aider ses élèves à mémoriser les fondamentaux ;
- Proposer des exercices courts entre deux cours ;
- Diversifier les méthodes d'apprentissage ;
- Identifier rapidement les notions que les élèves maîtrisent mal.

Elle pourrait donc utiliser DevFlash pour elle-même, mais surtout le recommander à ses étudiants.

### ❤️ Intérêts et préférences

Elle apprécie :

- Les outils pédagogiques simples, accessibles et écologiques ;
- Les ressources gratuites ou accessibles ;
- Les contenus structurés ;
- Les supports faciles à partager ;
- Les outils ne nécessitant pas de création de compte.

### 🚧 Défis et freins

Ses principales difficultés :

- Trouver des ressources suffisamment simples pour les débutants ;
- Eviter de surcharger les étudiants ;
- Trouver des outils adaptés à des niveaux différents ;
- Vérifier la qualité et la fiabilité des contenus.

Son principal frein vis-à-vis de DevFlash serait :

- La quantité et la qualité des flashcards disponibles.
- Si le contenu est trop limité ou comporte des erreurs, elle ne recommandera pas l'outil.

### 💡 Ce que DevFlash lui apporte

- **Un support complémentaire pour faire réviser rapidement les notions fondamentales à ses apprenants.**

Priorité : ⭐⭐⭐

## 3. Cible fictive directe — Aziz

> Profil correspondant à une cible que DevFlash pourrait chercher à conquérir à moyen terme.

👤 Aziz Lumière
| Élément    | Profil                              |
|------------|-------------------------------------|
| Âge        | 38 ans                              |
| Lieu       | Bordeaux, France                    |
| Activité   | Développeur full-stack confirmé     |
| Expérience | 12 ans                              |
| Langages   | TypeScript, Python, Java, SQL       |

### 🌐 Comportement en ligne

Aziz utilise régulièrement :

- Les documentations officielles ;
- La documentation d'entreprise ;
- GitHub ;
- Stack Overflow ;
- Les newsletters techniques ;
- Les blogs spécialisés.

Il apprend principalement au fil de ses projets.

### 🎯 Motivation et objectifs

Lucas souhaite maintenir ses connaissances à jour et découvrir de nouvelles technologies.

Il pourrait être intéressé par DevFlash pour :

- Revoir rapidement certaines notions oubliées ;
- Découvrir des fonctionnalités moins utilisées ;
- Préparer une transition vers un nouveau langage ;
- Effectuer une révision rapide avant un entretien ou une certification.

### ❤️ Intérêts et préférences

Il préfère :

- Des contenus plus avancés ;
- Des questions précises ;
- Des cas pratiques ;
- Des raccourcis et astuces ;
- Des fonctionnalités permettant de personnaliser son apprentissage.

Il apprécie les outils qui vont droit au but.

### 🚧 Défis et freins

Son principal problème n'est pas l'apprentissage des fondamentaux.

C'est plutôt :

- Maintenir un niveau de connaissance élevé dans un écosystème qui évolue rapidement.

Il pourrait cependant considérer les flashcards trop basiques.

### 💡 Ce que DevFlash pourrait lui apporter

- **Un outil de réactivation rapide des connaissances et de découverte de notions avancées.**

Priorité actuelle : ⭐⭐
> Note : Ce profil devient particulièrement intéressant si DevFlash évolue ensuite vers des niveaux débutant → intermédiaire → avancé.

## 4. Cible fictive indirecte — Sylvie

> Personne qui pourrait influencer l'adoption de DevFlash sans être l'utilisateur principal.

👤 Sylvie Dasilva
| Élément    | Profil                                                          |
|------------|-----------------------------------------------------------------|
| Âge        | 42 ans                                                          |
| Lieu       | Paris, France                                                   |
| Activité   | Engineering Manager / responsable d'une équipe de développement |
| Expérience | 15 ans dans la tech                                             |

### 🌐 Comportement en ligne

Claire utilise principalement :

- LinkedIn ;
- GitHub ;
- Newsletters professionnelles ;
- Plateformes de formation ;
- Ressources de veille technologique.

Elle ne passe pas beaucoup de temps à tester des outils techniques elle-même.

### 🎯 Motivation et objectifs

Claire cherche surtout à :

- Accompagner la montée en compétences de son équipe ;
- Faciliter l'onboarding des développeurs juniors ;
- Identifier des ressources de formation pertinentes ;
- Favoriser une culture d'apprentissage continu.

### ❤️ Intérêts et préférences

Elle privilégie :

- Les outils simples ;
- Les solutions faciles à adopter ;
- Les ressources fiables ;
- Les outils ne nécessitant pas une configuration complexe ;
- Les solutions pouvant être recommandées à toute une équipe.

### 🚧 Défis et freins

Son principal défi :

- Faire monter rapidement en compétence des développeurs juniors sans monopoliser le temps des développeurs seniors.

Son principal frein :

- Fiabilité du contenu ;
- Manque éventuel de fonctionnalités de suivi ;
- Absence de statistiques ;
- Absence de gestion d'équipe.

### 💡 Ce que DevFlash pourrait lui apporter

À terme :

- Un outil complémentaire d'onboarding et de montée en compétences pour les développeurs juniors.

Priorité actuelle : ⭐
> Note : Ce profil est clairement hors cible V1, mais intéressant pour réfléchir à l'évolution du produit.
